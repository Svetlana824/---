***Игра «Крестики-нолики» (Tic-Tac-Toe)***

Добро пожаловать в классическую игру «Крестики-нолики», реализованную на платформе Windows Forms (C#). Это простой и понятный проект, который отлично подходит для демонстрации базовой логики работы с интерфейсом и обработкой событий.

***Описание игры***

Это пошаговая игра для двух игроков на одном устройстве. Главная цель — первым собрать непрерывную линию из трех своих символов (крестиков или ноликов). Линия может быть горизонтальной, вертикальной или диагональной.
Игровое поле представляет собой сетку 3×3.

***Как играть***
**1. Старт игры:** При запуске программы игровое поле пустое. Право первого хода по умолчанию принадлежит игроку, играющему за «X».

<img width="520" height="517" alt="image" src="https://github.com/user-attachments/assets/587d6617-ffbb-4ff7-b249-b0fb34b8766d" />
   
**2. Процесс:** Чтобы сделать ход, просто кликните левой кнопкой мыши по любой свободной клетке. Выбранный символ появится в клетке, а нажатая кнопка заблокируется.

**3. Смена хода:** После каждого хода программа автоматически передает очередь другому игроку. Текущий игрок отображается в специальном индикаторе в нижней части окна.

**4. Завершение раунда:**

*Победа:* Если один из игроков выстроил три своих символа в ряд, игра останавливается, появляется сообщение о победе, а все клетки блокируются.

***Технические особенности***

В проекте реализована следующая логика:

1. Использование двумерного массива кнопок (Button[,]) для удобной проверки выигрышных комбинаций.

2. Отдельные методы для проверки строк, столбцов и диагоналей (CheckRows, CheckColumns, CheckDiagonals).

3. Блокировка уже использованных ячеек для предотвращения случайных повторных нажатий.

4. Динамическое обновление интерфейса (метки текущего хода и сообщения о результате).


***Как запустить***

1. Склонируйте репозиторий или скачайте архив с проектом.

2. Откройте файл решения TicTacToe.sln в Microsoft Visual Studio.

3. Нажмите F5 или кнопку «Пуск» (Start), чтобы собрать и запустить игру.
